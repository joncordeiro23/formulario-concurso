# Formulário de Inscrição para Concurso

## Projeto desenvolvido em Python

Este programa simula um inscrição para concurso público.

### Funcionalidades

- Cadastro do candidato;
- Validação de idade;
- Escolha de escolaridade;
- Escolha da área profissional;
- Uso comandos condicionais

# Tecnologias utilizadas

- Python
- VS Code
- Git
- GitHub
